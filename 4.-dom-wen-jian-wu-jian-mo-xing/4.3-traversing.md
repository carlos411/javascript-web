# 4.3 節點查找(Traversing)

## 往內層找



### .querySelector() 與 .querySelectorAll()

往內層找特定的元素，找一個就用 `.querySelector()`, 找多個就用 `.querySelectorAll()`。

### 找第 n 個子元素

透過 querySelector 往內層找，以及使用 CSS 選取器當中的偽類別 `:nth-child()`：

```javascript
var my_block = document.getElementById("my_block");

var nth_child = my_block.querySelector("ul.my_list > li:nth-child(2)");
```
