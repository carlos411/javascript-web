# 8.2 Arrow Function

## arrow function 寫法

### 範例 1

```javascript
// 寫法一
my_btn.addEventListener("click", function(){
  alert("s");
});

// 寫法二
my_btn.addEventListener("click", () => {
  alert("abc");
});

// 寫法三
my_btn.addEventListener("click", () => alert("abc"));

// 與寫法二相同，只是帶入「事件物件」參數
my_btn.addEventListener("click", (e) => {
  alert(e.target.id);
});
```

### 範例 2

以下三個寫法結果是相同的：

```javascript
// 寫法一
var add = function(a, b){
  return a + b;
};

// 寫法二
var add = (a, b) => {
  return a + b;
};

// 寫法三
var add = (a, b) => a + b;
```
