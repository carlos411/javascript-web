# 5.3 window 及 document 事件

## 載入的相關事件

### DOMContentLoaded

```javascript
document.addEventListener("DOMContentLoaded", function(){
  // DOM 載入完成之後
});
```

### load

```javascript
window.addEventListener("load", function(){
  // 圖片等資源載入完成之後
});
```
